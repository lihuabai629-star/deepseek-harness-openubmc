# 领域文档

[English](domain.md) | 中文

本 monorepo 使用共享术语表和子系统文档。探索某个领域前，阅读[术语表](../glossary.zh.md)、[架构](../architecture.zh.md)及相关[子系统页面](../subsystems/README.zh.md)。Issue、规格和代码使用这些文档定义的术语。

通过相关有效 [Agent Notes](../../.agents/notes/README.zh.md)了解架构决策。记录持久决策时遵循其生命周期和分类规则。归档笔记是历史记录，不是当前依据。提议替换有效决策前，明确说明冲突。

这些位置承担工程技能所需的术语表和 ADR 职责。扩展现有权威文档，不另建重复的根目录 `GLOSSARY.md`、`GLOSSARY-MAP.md` 或 `docs/adr/` 体系。缺失术语在领域建模时处理，不阻塞探索。
