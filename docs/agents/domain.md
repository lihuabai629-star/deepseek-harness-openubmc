# Domain documentation

English | [中文](domain.zh.md)

This monorepo uses a shared glossary and subsystem documentation. Read [the glossary](../glossary.md), [architecture](../architecture.md), and the relevant [subsystem pages](../subsystems/README.md) before exploring an area. Use their terms in issues, specifications and code.

Read relevant active [Agent Notes](../../.agents/notes/README.md) for architectural decisions. Follow their lifecycle and classification rules when recording a durable decision. Archived notes are historical records, not current authority. State a conflict with an active decision explicitly before proposing its replacement.

These locations fulfill the glossary and ADR roles expected by engineering skills. Extend the existing owners rather than creating duplicate root `GLOSSARY.md`, `GLOSSARY-MAP.md` or `docs/adr/` trees. Missing domain terms are handled when the domain is modeled; they do not block exploration.
