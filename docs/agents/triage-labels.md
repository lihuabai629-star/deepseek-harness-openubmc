# Triage labels

English | [中文](triage-labels.zh.md)

Engineering skills use the following GitHub labels. They describe readiness and coexist with the repository’s `kind/*`, `area/*` and Issue Type conventions.

| Role | Label |
|---|---|
| needs-triage | `needs-triage` |
| needs-info | `needs-info` |
| ready-for-agent | `ready-for-agent` |
| ready-for-human | `ready-for-human` |
| wontfix | `wontfix` |

`needs-triage` awaits evaluation; `needs-info` awaits missing information; `ready-for-agent` is specified for autonomous implementation; `ready-for-human` requires human implementation; `wontfix` will not be implemented.
