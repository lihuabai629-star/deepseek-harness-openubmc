# 分流标签

[English](triage-labels.md) | 中文

工程技能使用以下 GitHub 标签。它们描述任务就绪状态，与仓库的 `kind/*`、`area/*` 和 Issue Type 约定并存。

| 角色 | 标签 |
|---|---|
| needs-triage | `needs-triage` |
| needs-info | `needs-info` |
| ready-for-agent | `ready-for-agent` |
| ready-for-human | `ready-for-human` |
| wontfix | `wontfix` |

`needs-triage` 等待评估；`needs-info` 等待补充信息；`ready-for-agent` 已具备自主实现所需规格；`ready-for-human` 需要人工实现；`wontfix` 不予实现。
